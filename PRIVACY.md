# Privacy

This plugin sends the medicine, brand or provider name a tool is called with, and nothing else, to GLP1Prices.co's public MCP server at https://glp1prices.co/api/mcp to look up prices. It sends no user identity, conversation text, credentials or files, needs no account or API key, and stores nothing.

GLP1Prices.co's server answers from public price data and does not keep the questions it is asked beyond ordinary web server request logs. GLP1Prices.co's own privacy policy: https://glp1prices.co/legal/privacy
